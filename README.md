# Клиент-серверное приложение на Java (Socket API)

## 📋 Описание задачи

Создать клиент-серверное приложение на Java с использованием `ServerSocket` 
и `Socket`:
- **Сервер** принимает входящее соединение, читает строку и выводит её на экран 
  вместе с номером порта клиента.
- **Клиент** подключается к серверу и отправляет одну строку.

## 🎯 Цель

Отработать:
- Создание сервера через `ServerSocket`;
- Подключение клиента через `Socket`;
- Работу с потоками ввода-вывода (`BufferedReader`, `PrintWriter`);
- Понимание сетевого взаимодействия по протоколу TCP.

## 🛠️ Используемые технологии

- Java 17+
- `ServerSocket` / `Socket`
- `BufferedReader` / `PrintWriter`
- `InputStreamReader` / `OutputStream`
- Многопоточность (для одновременной работы сервера и клиента)
